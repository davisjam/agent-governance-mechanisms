If a model is where you now start, this Part shows the models worth keeping. Model-based
engineering never failed on its ideas; it failed on the expense of maintaining the models —
an expense a fleet of agents now pays cheaply. You will walk Kruchten's four-plus-one views,
promoted from a passing reference to the working spine: the logical, process, development,
physical, and scenarios views of a real system, each an executable model joined to the code it
describes rather than a second copy of the truth. Along the way you will learn how to read a
model page, how far to model before reaching for a heavier tool, and how a two-layer net keeps
every model equal to the territory it maps.
